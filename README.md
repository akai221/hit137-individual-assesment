# HIT137 Assignment 3 - Tile Puzzle

Needs opencv-python and numpy. Run with `python main.py`.

Pick a grid size, then load an image. The picture gets cut up and scrambled.

- Left click a tile to select it, then click another tile to swap them
- Right click rotates a tile
- Shift + left click flips a tile
- Hint shows a wrong tile (3 per image)
- Solve finishes the puzzle
